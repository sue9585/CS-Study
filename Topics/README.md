> **운영 팁**:
> - 총 7명이므로, **화요일 3명 / 목요일 4명** (혹은 매회 3\~4명씩 순환) 발표를 진행하면 1주에 7명 전원이 1회씩 발표를 완료할 수 있습니다.

| 주차 | 회차 (날짜) | 발표 주제 (DS / NW) | 진행 현황 |

## ☕ 모임 진행 순서 (카페 모임 시)
1. **모임 시작 (10분)**: 각자 음료 주문 및 자리 세팅, PR 제출 확인
2. **단기 발표 및 Q&A (45\~50분)**:
   - 발표자당 5분 내외 발표 (작성한 `.md` 파일 또는 도식 중심)
   - 스터디원 꼬리 질문 (5분)
3. **상호 리뷰 & Merge (10분)**:
   - GitHub PR에 질문이나 피드백 코멘트 남기기
   - Approve 확인 후 Merge
   - 다음 회차 발표자 및 주제 확정
